# 🎯 | Challenge  <a id="Challenge"></a>
A development environment should be adapted to the specific needs of each project. However, working with different types of tasks in a single editor configuration can lead to unnecessary extensions, inconsistent settings, and reduced productivity.

The challenge of this academic activity was to customize Code-OSS by configuring its appearance, keyboard shortcuts, extensions, settings, and workspace profiles.

The main objective was to create a dedicated Markdown Documentation profile, allowing the editor to provide a more organized and efficient environment for writing and managing technical documentation.

# 💡 | Solution  <a id="Solution"></a>
The customization was performed using Code-OSS 1.138.0 on CachyOS.

The main configurations included:
- Profile: Created a profile named Documentación Markdown.
- Theme: Midnight Dracula.
- Font: JetBrains Mono, with Hack as fallback.
- Autosave: Configured to afterDelay.
- Format on Save: Enabled.
- Extensions:
  - Markdown All in One
  - Markdown Preview Enhanced
  - Markdownlint
  - CodeSnap
  - ESLint
  - GitLens
  - Live Server
  - Material Icon Theme
  - Prettier
  - among others.
    
-Snippets: Created custom snippets for Mermaid diagrams, Java code blocks, centered images and highlighted notes.

Keyboard shortcuts: Customized shortcuts to improve the editing workflow.
